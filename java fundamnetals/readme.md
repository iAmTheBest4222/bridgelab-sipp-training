## 🏆 Problems List

| Problem | Statement |
|---------|-----------|
| **PS1** | Write a program to find the age of Harry if the birth year is 2000. Assume the Current Year is 2024.<br>**I/P:** NONE<br>**O/P:** Harry's age in 2024 is ___ |
| **PS2** | Sam’s mark in Maths is 94, Physics is 95 and Chemistry is 96 out of 100. Find the average percent mark in PCM.<br>**I/P:** NONE<br>**O/P:** Sam’s average mark in PCM is ___ |
| **PS3** | Create a program to convert the distance of 10.8 kilometers to miles.<br>_Hint:_ 1 km = 1.6 miles<br>**I/P:** NONE<br>**O/P:** The distance ___ km in miles is ___ |
| **PS4** | Create a program to calculate the profit and loss in number and percentage based on the cost price of INR 129 and the selling price of INR 191.<br>_Hint:_<br>- Profit = selling price - cost price<br>- Profit Percentage = profit / cost price * 100<br>- Use a single print statement to display multiline text and variables.<br>**I/P:** NONE<br>**O/P:**<br>The Cost Price is INR ___ and Selling Price is INR ___<br>The Profit is INR ___ and the Profit Percentage is ___ |
| **PS5** | Suppose you have to divide 14 pens among 3 students equally. Write a program to find how many pens each student will get if the pens must be divided equally. Also, find the remaining non-distributed pens.<br>_Hint:_<br>- Use Modulus Operator (%) to find the remainder.<br>- Use Division Operator to find the quantity of pens.<br>**I/P:** NONE<br>**O/P:** The Pen Per Student is ___ and the remaining pen not distributed is ___ |
| **PS6** | The University is charging the student a fee of INR 125000 for the course. The University is willing to offer a discount of 10%. Write a program to find the discounted amount and discounted price the student will pay for the course.<br>_Hint:_<br>- Create a variable named fee and assign 125000 to it.<br>- Create another variable discountPercent and assign 10 to it.<br>- Compute discount and assign it to the discount variable.<br>- Compute and print the fee you have to pay by subtracting the discount from the fee.<br>**O/P:** The discount amount is INR ___ and final discounted fee is INR ___ |
| **PS7** | Write a Program to compute the volume of Earth in km^3 and miles^3.<br>_Hint:_ Volume of a Sphere is (4/3) * pi * r^3 and radius of earth is 6378 km<br>**O/P:** The volume of earth in cubic kilometers is ____ and cubic miles is ____ |
| **PS8** | Create a program to convert distance in kilometers to miles.<br>_Hint:_<br>- Create a variable km and assign type as double.<br>- Use Scanner Object to take user input for km.<br>- Use 1 mile = 1.6 km formula to calculate miles and show the output.<br>**I/P:** km<br>**O/P:** The total miles is ___ mile for the given ___ km |
| **PS9** | Write a new program similar to PS6 but take user input for Student Fee and University Discount.<br>**I/P:** fee, discountPercent<br>**O/P:** The discount amount is INR ___ and final discounted fee is INR ___ |
| **PS10** | Write a program that takes your height in centimeters and converts it into feet and inches.<br>_Hint:_ 1 foot = 12 inches and 1 inch = 2.54 cm<br>**I/P:** height<br>**O/P:** Your Height in cm is ___ while in feet is ___ and inches is ___ |
| **PS11** | Write a program to create a basic calculator that can perform addition, subtraction, multiplication, and division. The program should ask for two numbers (floating point) and perform all the operations.<br>**I/P:** number1, number2<br>**O/P:** The addition, subtraction, multiplication and division value of 2 numbers ___ and ___ is ___, ____, ____, and ___ |
| **PS12** | Write a program that takes the base and height to find area of a triangle in square inches and square centimeters.<br>_Hint:_ Area of a Triangle is ½ * base * height<br>**I/P:** base, height<br>**O/P:** The Area of the triangle in sq in is ___ and sq cm is ___ |
| **PS13** | Write a program to find the side of the square whose perimeter you read from user.<br>_Hint:_ Perimeter of Square is 4 times side<br>**I/P:** perimeter<br>**O/P:** The length of the side is ___ whose perimeter is ____ |
| **PS14** | Write a program to find the distance in yards and miles for the distance provided by user in feet.<br>_Hint:_ 1 mile = 1760 yards and 1 yard is 3 feet<br>**I/P:** distanceInFeet<br>**O/P:** The distance in yards is ___ while the distance in miles is ___ |
| **PS15** | Write a program to input the unit price of an item and the quantity to be bought. Then, calculate the total price.<br>**I/P:** unitPrice, quantity<br>**O/P:** The total purchase price is INR ___ if the quantity ___ and unit price is INR ___ |
| **PS16** | Create a program to find the maximum number of handshakes among N number of students.<br>_Hint:_<br>- Use the combination = (n * (n - 1)) / 2 formula to calculate the maximum number of possible handshakes.<br>**I/P:** numberOfStudents<br>**O/P:** The number of possible handshakes is ___ |

## 💡 How to Use

- **Choose a problem** (e.g., PS3, PS10).
- **Read the statement and hints**.
- **Write your code** in your preferred programming language.
- **Test** with sample inputs and compare your output with the expected format.
