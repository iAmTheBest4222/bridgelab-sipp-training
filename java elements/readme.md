Coding Problems Collection
Welcome! This repository contains a set of beginner-friendly programming problems aimed at helping you practice basic computational thinking and coding skills. Each question is labeled as Qone, Qtwo, etc., for easy reference.

Qone: Calculate the Volume of Earth

Hint: Volume of a sphere = (4/3) × π × r³; Earth's radius = 6378 km.
Output: The volume of earth in cubic kilometers is ____ and cubic miles is ____1.
